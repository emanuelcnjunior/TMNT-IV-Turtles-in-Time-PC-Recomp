# v1.0.2 — Hotkeys e Save Game

Instalador Windows com o executável aprovado que inclui os atalhos rápidos de salvamento e carregamento.

- Cinco slots manuais e um Quick Save em `%LOCALAPPDATA%\TMNTIVRecomp\saves`.
- F1/F2 no teclado e LT/RT no controle para salvar/carregar rapidamente.
- F11 abre a lista de saves; os atalhos podem ser configurados no menu do launcher.
- Start no controle ou F6 no teclado alterna Original/HD durante a partida. Scale2x segue como filtro padrão.
- O instalador não inclui a ROM; o jogador seleciona sua própria ROM USA original durante a instalação.
